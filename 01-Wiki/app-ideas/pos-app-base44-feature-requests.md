# POS App Feature Requests — Base44

**Summary:** Comprehensive list of feature requests for a restaurant and karaoke bar POS app called Base44. Written from the perspective of a bar/karaoke venue manager. Covers menu structure, manager controls, room and table timers, bill splitting, reservation automation, hardware output, and payment integrations. This is a full product wishlist likely sent to the Base44 team.

## Key Points
- Manager should see the home screen by default, not servers.
- Menu needs subcategory pricing tiers within a single item (Mix / Rocks / Shot at different prices).
- Room and table timers must be pausable, resumable, with notes and time-add options.
- Bill splitting must split by what each individual in a room actually ordered.
- Stripe or Square integration, auto-tax, and tip options required.

## Menu and Ordering
- Allow reordering of categories.
- Add Allergy Notes section — allergies display in a distinct color.
- Subcategory pricing: e.g., under "Casamigos Tequila" → Mix $16 / Rocks $12 / Shot $10 (up to 4 tiers). Same for food: "Pasta" → Penne / Spaghetti / Linguine / Gluten-free.
- Each item can have its own custom alarm (e.g., kitchen alert if fries take more than 20 min).

## Manager Controls
- Manager home screen shows karaoke rooms and tables with: guest count editor, room/table timers (pause, resume, stop, add time, leave notes, add orders like a server).
- Manager is the only one who can change prices or remove items.
- Add employee PIN system: add, remove, edit.
- Customizable sound or vibration notifications at 1, 5, 10, or 20-minute intervals for servers and kitchen.
- Monthly item sales and time analytics.
- Server section so each server tracks their own tips and is accountable for mistakes.

## Billing and Reservations
- Split bill by what each individual in the room or table actually ordered (not just an even split).
- Customizable minimum order option.
- Reservation section: upcoming and past reservations.
- Auto-fill table/room on new reservation to prevent double-booking.
- Auto-email to late reservations with customizable time window warning that the reservation will be canceled if no reply.

## Hardware and Integrations
- HDMI output: display all current orders on a TV screen (tablet may be too small for high volume).
- Allow the venue to run its own ads on the display screen.
- Stripe or Square payment integration.
- Auto-tax calculation.
- Tip options at payment.
- Marketing automation integration.
- Karaoke room timers linked to the POS system.
