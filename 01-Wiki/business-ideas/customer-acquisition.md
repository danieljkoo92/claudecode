STEP 8 — CREATE THE DATA COLLECTOR PAGE

Tell Codex:

“Build a Data Collector page where I can paste a public play-by-play URL and collect game data.”

Page should include:
• URL input box
• Collect Game Data button
• Status area
• Extracted substitution events table
• Export JSON button
• Export CSV button
• Error messages
• Data Status card

If no data exists, show:
“No games collected yet.”

If the page fails, show:
“Could not extract substitution events from this page. The layout may have changed or the page may not contain substitution data.”
