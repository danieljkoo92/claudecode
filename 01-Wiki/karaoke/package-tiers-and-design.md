# Package Tiers and Design Brief

**Summary:** The four package tiers with what each one saves a customer, plus a design instruction for how the packages should be presented. The savings figure is meant to be the biggest thing on the card — larger than the package name itself — and the styling should read luxury, in the vein of Louis Vuitton or Balenciaga.

## Key Points
- Four tiers: **Bronze, Silver, Gold, Platinum**.
- Savings run from **$11 to $30 per person**.
- **"Saves" is the hero text** — deliberately larger than the package names.
- Style reference: **Louis Vuitton / Balenciaga** — luxury fonts.

## The Tiers
| Package | Saves up to |
|---|---|
| Bronze | **$11 per person** |
| Silver | **$14 per person** |
| Gold | **$24 per person** |
| Platinum | **$30 per person** |

## The Design Brief
> More luxury style — Louis Vuitton, Balenciaga style font. And I want the text **Saves** to be the main thing here, so way larger. Text can be larger than the actual package names.

## Why Lead With Savings
Making the saving bigger than the package name is the right call. A customer choosing between hourly and a package is doing arithmetic in their head at the front desk — putting the answer in the largest type removes that work and makes the package the obvious choice. It also arms staff: the pricing SOP requires mentioning current packages, and "this one saves you $24 a head" is a faster sell than listing what is included.

The redesign also had a second purpose recorded elsewhere — showing staff that management cares whether packages sell. A cheap-looking card signals that nobody minds either way. See [[manager-argument-the-numbers|Manager Argument — The Numbers]].
