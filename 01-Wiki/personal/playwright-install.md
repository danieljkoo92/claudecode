# Playwright Installation

**Summary:** Extracted from bulk notes file.

STEP 2 — INSTALL PLAYWRIGHT

Tell Codex:

“Install Playwright and set it up for browser automation.”

Codex should run:

npm install -D playwright
npx playwright install

Playwright will be used to open public play-by-play pages in a browser and collect substitution events.

Playwright is not the app.
Playwright is just the browser automation tool.

Agent Mode is the worker.
Playwright is the browser tool.
